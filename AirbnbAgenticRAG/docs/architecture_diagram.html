On a cache HIT: the full pre-built answer is returned immediately — no embedding, no Vector Search, no LLM call. On a cache MISS: the full pipeline runs and the final answer is stored for 1 hour (3 600 s TTL).

③ Agentic · /ask Agentic RAG — Redis Cache Decision + ReAct Loop
How Redis is used in app/main.py → ask(): Cache key = ask:<sha256(query)>. On a cache HIT the full AgentResponse is returned instantly — the ReAct loop, every tool call, and every Gemini call are completely skipped. On a cache MISS the full agentic pipeline runs and the result is stored for 30 min (CACHE_ASK_TTL = 1800s).
Additionally, each individual find_rentals() tool call has its own inner cache keyed on ask:<sha256(query + all_filters)> — a tool-level HIT skips embedding + Vector Search for that call.
